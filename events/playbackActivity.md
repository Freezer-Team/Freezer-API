# `playbackActivity`

播放器活动状态变化时触发。

| 方法 | 类型 | 含义 |
| --- | --- | --- |
| `getAppRecord()` | 应用对象 | 播放器所属应用 |
| `getEvent()` | `int` | 播放器状态事件，见下表 |
| `getId()` | `int` | 系统分配的播放器接口 ID |
| `isPlaying()` | `boolean` | 应用聚合播放状态；`true` 表示至少一个播放器已开始 |

`getEvent()` 值：

| 值 | 含义 |
| --- | --- |
| `-1` | 未知 |
| `0` | 已释放 |
| `1` | 空闲 |
| `2` | 已开始 |
| `3` | 已暂停 |
| `4` | 已停止 |

**阶段：** `NONE`  
**可取消：** 是。取消会阻止开始播放时解冻，或全部播放器停止后安排冻结。
